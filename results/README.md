Computational results, tables and figures obtained from the metabolic model analysis.
# Results

This directory contains computational results obtained from the analysis of the *Escherichia coli* genome-scale metabolic model iML1515.

## Results include

- Model optimization results.
- Hydrogen production fluxes.
- Anaerobic growth simulation results.
- Influence of glucose uptake on hydrogen production.
- Comparison of metabolic pathway constraints.
- Graphical representations of simulation results.

## Note

All results are computational predictions obtained using Flux Balance Analysis (FBA). They have not been experimentally validated.
