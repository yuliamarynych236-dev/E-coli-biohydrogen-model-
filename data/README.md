Metabolic model files used in this project.
# Data

This directory contains the metabolic model used in the computational analysis of hydrogen production in *Escherichia coli*.

## Files

- `iML1515.xml.gz` – genome-scale metabolic model of *E. coli* in SBML format.

## Description

The iML1515 model was used as the basis for metabolic simulations and Flux Balance Analysis (FBA) performed with COBRApy.

The model was used to investigate metabolic pathways associated with hydrogen production, anaerobic growth and substrate utilization.
