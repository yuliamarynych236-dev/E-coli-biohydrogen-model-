Python scripts used for metabolic model analysis, flux calculations and data processing.
# Scripts

This directory contains Python scripts developed for the computational analysis of hydrogen production in *Escherichia coli*.

## Planned scripts

- Model loading and preparation.
- Flux Balance Analysis (FBA).
- Hydrogen production analysis.
- Anaerobic growth simulations.
- Substrate uptake analysis.
- Processing and visualization of computational results.

## Software

Python and COBRApy.

The scripts are intended to support reproducibility and facilitate further analysis of the metabolic model.
