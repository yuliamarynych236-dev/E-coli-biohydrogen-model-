# Notebooks

This directory contains Jupyter notebooks used for computational analysis of hydrogen production in *Escherichia coli*.

## Files

- `E_coli_biohydrogen_analysis.ipynb` – main notebook containing the metabolic model analysis and computational simulations.

## Analysis

The notebook includes:

- Loading the iML1515 metabolic model.
- Evaluation of model characteristics.
- Analysis of formate hydrogen lyase (FHL).
- Simulation of anaerobic growth conditions.
- Investigation of glucose uptake and hydrogen production.
- Evaluation of selected metabolic pathway constraints.

## Software

Python, COBRApy, pandas and Matplotlib.
